# LifeOS — Obsidian Vault

Bộ template Obsidian cho LifeOS, thiết kế để đồng bộ với data model của backend (Activities, Events, Metrics).

## Cấu trúc

```
obsidian/
├── Templates/
│   ├── Daily Note.md          # Note hàng ngày — intentions, activities, metrics, reflection
│   ├── Weekly Review.md       # Review hàng tuần — breakdown, streaks, top activities
│   ├── Monthly Review.md      # Review hàng tháng — trend, books, projects, goals
│   ├── Activity Log.md        # Log một activity thủ công (source: manual)
│   ├── Reading Session.md     # Log session đọc sách từ KOReader
│   └── Coding Session.md      # Log activity code từ GitHub
├── Daily/                     # Daily notes (auto-generated by Obsidian)
├── Weekly/                    # Weekly reviews
└── Monthly/                   # Monthly reviews
```

## Setup

### 1. Tạo Obsidian Vault

Mở Obsidian → "Open folder as vault" → chọn thư mục `obsidian/`.

### 2. Cài Templater plugin

Settings → Community plugins → Browse → tìm **Templater** → Install → Enable.

Cấu hình Templater:
- Template folder location: `Templates`
- Enable folder templates: On
- Daily notes folder: `Daily`

### 3. Cấu hình Daily Notes

Settings → Daily notes:
- Date format: `YYYY-MM-DD`
- New file location: `Daily`
- Template file location: `Templates/Daily Note.md`

### 4. Cấu hình Weekly Notes (optional)

Settings → Weekly notes:
- Date format: `YYYY-[W]ww`
- New file location: `Weekly`
- Template file location: `Templates/Weekly Review.md`

## Template Overview

### Daily Note

Note hàng ngày gồm:
- **Morning Intentions** — 3 mục tiêu fokus
- **Activities Log** — bảng log reading (KOReader), coding (GitHub), và activities khác
- **Metrics** — bảng ghi numeric metrics
- **Energy & Mood** — self-tracking energy, mood, sleep
- **Highlights** — điều tốt nhất trong ngày
- **Reflections** — what went well / improve / ideas
- **Tomorrow** — prep cho ngày hôm sau

### Weekly Review

Review hàng tuần gồm:
- **Week at a Glance** — so sánh với tuần trước
- **Source Breakdown** — thời gian theo source (koreader, github, manual)
- **Category Breakdown** — thời gian theo category
- **Streaks** — current + best streak
- **Top Activities** — top 5 activities
- **Wins / Challenges / Lessons / Next Week Focus**

### Monthly Review

Review hàng tháng gồm:
- **Monthly Summary** — so sánh với tháng trước
- **Weekly Trend** — 4 tuần trong tháng
- **Top Activities** — top 5 tháng
- **Books Read** — bảng sách đã đọc
- **Projects Progress** — commits, PRs per repo
- **Reflection** — highlights, challenges, growth, improvement
- **Next Month Goals**

### Activity Log

Template cho activity thủ công. Frontmatter fields map trực tiếp với bảng `activities` trong DB:
- `source` — `manual` (hoặc connector khác)
- `category` — reading, coding, writing, exercise...
- `duration_minutes` — thời lượng
- `occurred_at` — timestamp

### Reading Session (KOReader)

Template cho reading session từ KOReader. Frontmatter fields map với event payload:
- `source: koreader`
- `title`, `author` — từ KOReader metadata
- `duration_seconds`, `pages_read`, `total_pages`, `device`

### Coding Session (GitHub)

Template cho GitHub activity. Frontmatter fields map với GitHub event:
- `source: github`
- `event_type` — commit, pull_request, issue, code_review...
- `repo`, `action`, `size`, `ref` — từ GitHub API payload

## Data Model Mapping

Template fields map trực tiếp với LifeOS backend:

| Template Field | DB Table | DB Column |
|---------------|----------|-----------|
| `source` | activities / events / metrics | `source` |
| `category` | activities | `category` |
| `title` | activities | `title` |
| `duration_minutes` | activities | `duration_minutes` |
| `occurred_at` | activities / events / metrics | `occurred_at` |
| `event_type` | events | `event_type` |
| `metric_name` | metrics | `metric_name` |
| `metric_value` | metrics | `metric_value` |
| `unit` | metrics | `unit` |

## Usage Workflow

1. Mỗi sáng: tạo Daily Note (Ctrl/Cmd + N hoặc click calendar)
2. Trong ngày: log activities vào bảng tương ứng
3. Cuối ngày: điền Highlights, Reflections, Tomorrow
4. Cuối tuần: tạo Weekly Review, aggregate từ daily notes
5. Cuối tháng: tạo Monthly Review, aggregate từ weekly reviews
